# zanexai-media

Public files for Zane AI social posts. Written by a script, read by Instagram, Threads, Facebook, TikTok and X.

- Videos and covers are assets of the release `media`. The workflow `pages` copies them to GitHub Pages:
  `https://leilajkaseme-hub.github.io/zanexai-media/<file>`.
- Branch `inbox`: `queue.json`, the list of posts for the Mac mini.
- Branch `results`: `results.json`, what the Mac mini posted.
- Files are deleted a few days after they are posted.
